
# Swagger Petstore API Testing

## Project Overview

This project contains API test cases created during testing of selected endpoints of the Swagger Petstore sample API.

The test cases document the tested scenarios, while the Postman collection contains the corresponding API requests that can be used to reproduce the checks.

## API Under Test

**Project:** Swagger Petstore

**API URL:** https://petstore.swagger.io/#/

## Test Artifacts

### 1. Test Cases

Detailed API test cases are available at the following link:

[View API Test Cases](https://github.com/users/Vrezhhakobyan1/projects/3/views/1)

### 2. Postman Collection

The Postman collection contains API requests used during testing.

The JSON file can be viewed directly on GitHub or imported into Postman to execute the requests.

# Русская версия

## Обзор проекта

Данный проект содержит тест-кейсы, разработанные в ходе тестирования отдельных API endpoints демонстрационного API Swagger Petstore.

Тест-кейсы описывают проверяемые сценарии, а коллекция Postman содержит соответствующие API-запросы, которые можно использовать для воспроизведения проверок.

**Проект:** Swagger Petstore

**URL API:** https://petstore.swagger.io/#/

Коллекция Postman содержит API-запросы, использованные в ходе тестирования.
